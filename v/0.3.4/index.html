sciafpad

A minimal GTK4 text editor built on top of Scintilla, specifically the bugaevc/scintilla GTK4 port.

It aims to be as simple as Leafpad, but uses Scintilla as the editing engine instead of GtkTextView. No syntax highlighting, no plugins — just a plain text editor.

Features

  • GTK4 native user interface
  • Scintilla-based text editing widget
  • Open / Save / Save As (via GtkFileDialog)
  • Undo / Redo / Cut / Copy / Paste (via Scintilla's SCI_* messages)
  • Window title reflects the current file name
  • About dialog
